SAMPLE REPORT PDF — drop the file here
======================================

Put your sample inspection report in THIS folder using this EXACT filename:

  sample-report.pdf

Full path in the project:
  wth-website/public/assets/reports/sample-report.pdf

The page at /sample-report checks for this file automatically:
  - If the PDF is present  -> it shows the embedded viewer + Download / Open buttons.
  - If it is missing       -> it shows a "coming soon" placeholder with a LINE button.
So the page is safe to publish before the PDF exists; it activates itself once you add the file.

IMPORTANT — privacy (PDPA):
  This sample is PUBLIC. Before uploading, REDACT any customer personal data:
  name, address, phone, email, project/unit number, or anything that identifies
  a real customer. The page already tells visitors the details are redacted.

Tips:
  - Keep the file reasonably small (ideally under ~5 MB) so it loads fast.
  - Lowercase filename only (the live server is case-sensitive).
