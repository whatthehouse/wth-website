CONTACT PAGE IMAGES — drop your real photos here
================================================

Put the Contact-page photos in THIS folder using these EXACT filenames.
Any format is fine (jpg / png / webp) — they will be optimized to WebP.

IMPORTANT: use lowercase folder + file names. The live server (Netlify/Linux)
treats "Contact" and "contact" as DIFFERENT folders, even though Windows does not.
A capitalised name works on your PC but breaks the image on whatthehouse.net.

HERO BACKGROUND (wide, landscape ~1536x1024 or larger):
  contact-hero.jpg        — ที่ปรึกษากำลังอธิบายรายงานให้ลูกค้า (ใช้เป็นพื้นหลังหัวหน้า)

Full path in the project:
  wth-website/public/assets/img/contact/
